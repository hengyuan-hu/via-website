# VIA Website

Static site for **VIA: Visual Interface Agent for Robot Control**.

Self-contained: page files at the root, all rollout videos, transcripts, and
tool demo clips under `data/`. No build step is needed to view it.

## View locally

```bash
python3 -m http.server 7899   # from the repo root
```

Then open <http://localhost:7899/>.

## Editing

This repo is checked out inside the research repo (`via-dev/via-website/`),
whose `website.md` documents the workflow: `index.html`, `app.js`, and
`style.css` are edited here directly, while `manifest.json`, `tools.json`,
the media under `data/`, and the figures under `assets/` are generated by the
research repo's `tools/` scripts. Pushing `main` deploys the site.
